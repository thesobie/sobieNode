# SOBIE 2026 Conference Website

This repository contains the static website for the SOBIE (Society of Business, Industry, & Economics) 2026 Annual Academic Conference.

## About SOBIE 2026

**Conference Dates:** April 8-10, 2026 (Wednesday-Friday)  
**Location:** Sandestin Golf and Beach Resort, Miramar Beach, Florida  
**Conference:** 26th Annual Academic Conference

## Features

- **Responsive Design:** Bootstrap 5 with mobile-first approach
- **Conference Information:** Complete details about SOBIE 2026
- **Interactive Modals:** About SOBIE, JOBIE Journal, Venue Details, Past Conferences
- **Student-Friendly:** Free registration for students, research opportunities highlighted
- **Contact Integration:** Email copying functionality with modern clipboard API

## Quick Start

### Local Development
```bash
# Using Python (recommended)
python serve.py
# Then open http://localhost:8080

# Or using Python's built-in server
python -m http.server 8080
# Then open http://localhost:8080
```

### Deployment
Simply upload `index.html` to your web server. The page is completely self-contained with CDN resources.

## About SOBIE

Founded in 1995, SOBIE encourages business faculty to respond to current economic and market issues. The society welcomes research from faculty, professionals, doctoral candidates, graduate students, and undergraduate students.

**Student Research is especially encouraged and welcomed!**
